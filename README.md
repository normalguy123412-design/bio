# bio

Персональная страница в виде ночной сцены в духе «живого» веба: заставка с
выбором языка и музыки, погодный слой (дождь, гроза, снег, ясное небо),
огромный курсивный ник, по которому стекает вода, рельс ссылок со
светлячком, стеклянный «остров» навигации с часами по Москве, стакан
громкости с плеском и полоса перемотки по нижнему краю.

**Адрес:** https://normalguy123412-design.github.io/bio/

## Порядок появления

1. Заставка — чёрный экран с плавающими «чернилами». По центру: выбор
   языка (русский/английский), затем вопрос «Включить музыку ?».
2. Буквы названия отваливаются вниз, и открывается сцена: фоновая запись,
   дождь, ник с отражением и водой по буквам, рельс ссылок справа.
3. «Остров» сверху: пункты разделов, кнопка музыки и переключатель языка;
   справа — часы по Москве.
4. При прокрутке вниз сцена димится, а под «островом» появляется
   мини-остров с текущим треком. Разделы: карточки «обо мне», затем строки
   «где меня искать». Кнопка «письмецо» на рельсе открывает стеклянный
   лист поверх всего.

Погодный режим выбирается сам (дождь чаще грозы). Ссылкой можно форсировать
конкретный: `/bio/?wx=snow`, `?wx=sun`, `?wx=storm`, `?wx=rain`.

## Язык

Разметка изначально русская; словарь (`lang.tsx`) переводит её на
английский. Выбор запоминается в `localStorage` (`niceguy.lang`),
переключается и кнопкой на «острове», и из заставки.

## Музыка

Заставка честно спрашивает «Включить музыку ?» — браузеры не дают включать
звук без действия человека. выбор хранится: громкость и «без звука» — в
`localStorage`, факт входа в сцены — в `sessionStorage`, так что повторное
открытие в той же вкладке заставку пропускает.

Поменять трек: положить файл в `public/track.mp3` (или поправить
`track.src` в `src/lib/profile.ts`). Формат — MP3 или OGG; FLAC не
подойдёт.

## Discord

Карточка берёт состояние из облака: бот (папка `discord/bot`) читает
активность, Worker (`discord/worker`) её раздаёт. Адрес задаётся в
`presenceEndpoint`. Иконка сервера, название и число онлайн приходят по
коду приглашения — поле `invite`.

## Запуск

```bash
npm install
npm run dev
```

Страница откроется на http://localhost:3000/ .

Сборка и проверка:

```bash
npm run lint
npm run build
```

Сборка под GitHub Pages (как в CI):

```bash
NEXT_PUBLIC_BASE_PATH=/bio npm run build
```
