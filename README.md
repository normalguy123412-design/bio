# bio

Персональная страница-сцена: огромный курсивный ник с отражением, «остров»
навигации, стеклянные карточки и плеер. Тёмная, ночная, с прокруткой.

**Адрес:** https://normalguy123412-design.github.io/bio/

## Что внутри

## Устройство страницы

Первый экран — сцена: огромный курсивный ник с отражением у нижнего края,
рельс ссылок у правого и стеклянный «остров» сверху. Дальше страница
прокручивается: раздел «Кто я такой» — три карточки (обо мне с календарём
коммитов, плеер и Discord), раздел «Написать мне» — строки со ссылками.

Чтобы добавить раздел: описать компонент в `sections.tsx` и вписать его в
`Experience` рядом с остальными в `site-shell.tsx`.

## Счётчик просмотров

Страница статическая, своего сервера у неё нет, поэтому число хранит внешний
сервис. Бесплатных без регистрации не осталось — создайте счётчик на
[counterapi.dev](https://counterapi.dev) и впишите адрес в `views.endpoint`
в `src/lib/profile.ts`:

```ts
export const views = {
  endpoint: "https://counterapi.dev/api/v1/<id-счётчика>/counter",
} as const
```

Пока адрес пустой или сервис не отвечает, счётчик не рисуется вовсе.

## Музыка

Первое, что видит посетитель, — заставка «со звуком?». Браузеры не дают
включать звук без действия пользователя, поэтому выбор делает человек:
«Включить музыку» или «Без звука». Трок играет по кругу, управляется из
трёх мест: из карточки плеера, из «острова» и из музыкального уголка на
первом экране.

Громкость и отключение звука сохраняются в localStorage, поэтому после
перезагрузки остаются прежними.

## Запуск

```bash
npm install
npm run dev
```

Страница откроется на http://localhost:3000/ .

Сборка и проверка:

```bash
npm run lint
npm run build
```

## Обновить календарь коммитов

Данные лежат в репозитории и не обновляются сами:

```bash
npm run sync:contributions
git commit -am "Календарь коммитов на свежую дату"
git push
```

Скрипт читает стандартный календарь активности GitHub и раскладывает дни в
`src/data/contributions.json`.

## Поменять музыку

Положите файл в `public/audio/` и поправьте `track.src` в `src/lib/profile.ts`.
Название и исполнитель берутся оттуда же.

Обложка кладётся рядом — `public/audio/cover.jpg` (квадрат, от 512×512);
путь прописан в `track.cover`. Пока файла нет, рисуется градиентная заглушка.

Формат: MP3 или OGG. **FLAC не подойдёт** — его умеют играть Safari и Firefox,
но не Chrome, и страница в Chrome будет молчать.

## Заменить ссылки и тексты

Всё в `src/lib/profile.ts`: имя, роли, описание, город и массив `links`.
Добавить свою иконку — дописать имя в `IconName` и компонент в `ICONS`
в `src/components/icons.tsx`.
