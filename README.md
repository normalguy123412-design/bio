# bio

Персональная страница: имя, роль, ссылки, календарь коммитов и плеер.

**Адрес:** https://normalguy123412-design.github.io/bio/

## Что внутри

| Файл | Зачем |
| --- | --- |
| `src/lib/profile.ts` | Все тексты и ссылки страницы. Единственное место, где их нужно менять |
| `src/components/icons.tsx` | Иконки и знак GitHub, которого нет в lucide |
| `src/components/site-shell.tsx` | Оболочка: открыт ровно один отдел, переключение кнопками |
| `src/components/rooms.tsx` | Отделы: профиль и активность |
| `src/components/social-buttons.tsx` | Стеклянные кнопки ссылок внизу профиля |
| `src/components/view-counter.tsx` | Счётчик просмотров |
| `src/components/ui/mac-os-dock.tsx` | Док у правого края экрана — единственный способ сменить отдел |
| `src/components/ui/contribution-skyline.tsx` | Календарь коммитов: плоская карта и 3D-скайлайн |
| `src/components/ui/text-shimmer.tsx` | Световая волна по имени и роли |
| `src/components/music-widget.tsx` | Значок звука в углу, плеер, громкость с сохранением |
| `src/data/contributions.json` | Коммиты за год, выгруженные с GitHub |
| `public/audio/track.mp3` | Музыка |
| `scripts/sync-contributions.mjs` | Обновляет `contributions.json` |

## Отделы

Отделы закрытые: открыт ровно один, и попасть в другой можно только кнопкой
в доке справа. Прокрутки страницы нет — ни колесом, ни клавишами. Внутри
отдела прокрутка осталась: на узком экране содержимое может не поместиться
по высоте.

Сейчас их два — «Профиль» и «Активность». Раньше был ещё отдельный отдел
«Ссылки», но кнопки ссылок переехали вниз карточки профиля: до них и так
видно сразу, без лишнего переключения.

Чтобы добавить отдел: описать компонент в `rooms.tsx`, вписать его в `ROOMS`
в `site-shell.tsx` и дописать раздел в `sections` в `profile.ts`.

## Счётчик просмотров

Страница статическая, своего сервера у неё нет, поэтому число хранит внешний
сервис. Бесплатных без регистрации не осталось — создайте счётчик на
[counterapi.dev](https://counterapi.dev) и впишите адрес в `views.endpoint`
в `src/lib/profile.ts`:

```ts
export const views = {
  endpoint: "https://counterapi.dev/api/v1/<id-счётчика>/counter",
} as const
```

Пока адрес пустой или сервис не отвечает, счётчик не рисуется вовсе.

## Музыка

Значок в правом нижнем углу открывает плеер поверх любого отдела.

Про автозапуск: браузеры не дают включать звук без действия пользователя, и
обойти это нельзя. Поэтому музыка начинает играть сама при первом
нажатии в любом месте страницы, а если и это не помогло, на значке остаётся
пульсирующее кольцо — звук включится кнопкой.

Громкость, отключение звука и раскрытое состояние панели сохраняются в
localStorage, поэтому после перезагрузки остаются прежними.

## Запуск

```bash
npm install
npm run dev
```

Страница откроется на http://localhost:3000/ .

Сборка и проверка:

```bash
npm run lint
npm run build
```

## Обновить календарь коммитов

Данные лежат в репозитории и не обновляются сами:

```bash
npm run sync:contributions
git commit -am "Календарь коммитов на свежую дату"
git push
```

Скрипт читает стандартный календарь активности GitHub и раскладывает дни в
`src/data/contributions.json`.

## Поменять музыку

Положите файл в `public/audio/` и поправьте `track.src` в `src/lib/profile.ts`.
Название и исполнитель берутся оттуда же.

Обложка кладётся рядом — `public/audio/cover.jpg` (квадрат, от 512×512);
путь прописан в `track.cover`. Пока файла нет, рисуется градиентная заглушка.

Формат: MP3 или OGG. **FLAC не подойдёт** — его умеют играть Safari и Firefox,
но не Chrome, и страница в Chrome будет молчать.

## Заменить ссылки и тексты

Всё в `src/lib/profile.ts`: имя, роли, описание, город и массив `links`.
Добавить свою иконку — дописать имя в `IconName` и компонент в `ICONS`
в `src/components/icons.tsx`.
